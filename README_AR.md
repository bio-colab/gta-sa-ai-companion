مشروع مفتوح المصدر يضيف **مرافقاً ذكياً مستقلاً ومجسداً بالكامل (Embodied AI NPC)** إلى لعبة **GTA San Andreas (الإصدار الأصلي v1.0 US)**. يمكنك الاقتراب من أي مواطن في الشارع، وضمه إلى فريقك عبر زر `H`، ثم التحدث معه صوتياً عبر الميكروفون المباشر (Push-to-Talk) ليرد عليك فوراً بنصوص ملونة داخل اللعبة وينفذ أوامرك الحركية والقتالية في العالم الحقيقي.

---

## 🌟 أبرز مميزات النظام

* **🎙️ التحدث الصوتي المباشر (Push-To-Talk)**:
  * اضغط مع الاستمرار على زر **`T`** في الكيبورد وتحدث بميكروفونك.
  * تحويل الكلام إلى نص فائق السرعة عبر **Groq Whisper Large v3 Turbo** بزمن استجابة أقل من 350 ميلي ثانية.
  * ظهور ردود الشخصية بترجمات ملونة واضحة على الشاشة (`Text.PrintStringNow`).

* **🧠 هوية ديموغرافية وذاكرة طويلة المدى (SQLite Episodic Memory)**:
  * توليد هوية فورية لكل مواطن: الاسم، الجنس، العمر، المهنة، نمط الشخصية، ونبرة الصوت.
  * قاعدة بيانات مستقلة (`memory.db`) تحفظ المحادثات السابقة والمواقف المشتركة حتى بعد إغلاق اللعبة وإعادة تشغيلها.
  * نظام ديناميكي للنقاط ومستوى الثقة والصداقة بين CJ والمرافق (من 0 إلى 100).

* **🛡️ اندماج تام مع محرك اللعبة الأصلي (`CPedGroup`)**:
  * استخدام نظام العصابات الأصلي للعبة بدون أي إضافات خارجية معقدة.
  * مرافقة CJ مشياً على الأقدام وركوب ومغادرة مقاعد الركاب في السيارات تلقائياً وبانسجام تام.

* **🎯 علامة الرادار الملاحية الذكية (Dynamic Radar Blip)**:
  * ظهور نقطة خضراء رسمية في رادار اللعبة الصغير تتبع تحركات المرافق.
  * **تحكم ذكي في الرؤية**: إخفاء السهم ثلاثي الأبعاد المزعج فوق رأسه تلقائياً عند القرب أو ركوب السيارة معاً (`BLIP_ONLY`)، وإظهاره فقط إذا تفرقتما وابتعد عنك لمسافة كبيرة لمساعدتك في العثور عليه.

* **🚗 طبقات الأوامر التكتيكية (Layered Modes)**:
  * **وضع المرافقة (`companion`)**: التبعية، الإسعاف واستعادة الصحة، توجيه الرأس والجسد.
  * **وضع القتال (`combat`)**: التسلح التلقائي بالأسلحة الثقيلة (M4، Desert Eagle، MP5، Shotgun) بدقة 85%، الاستسلام برفع الأيدي، إطلاق النار من السيارة.
  * **وضع المركبات (`vehicle`)**: جلب السيارات ذاتياً (الركض لأقرب سيارة وسرقتها والقيادة بها إلى CJ)، والقيادة إلى علامة الخريطة المستهدفة (Target Marker).
  * **وضع المشاعر والمرح (`emote`)**: الرقص في الحفلات، التدخين، الترنح كسكران، التشجيع، الخوف والاحتماء.

* **⚡ الاستجابة الذاتية لأحداث العالم (Ambient Intelligence)**:
  * **حوادث السير**: الصراخ أو التذمر إذا اصطدم CJ بالسيارة بقوة.
  * **راديو السيارة**: التعليق التلقائي على محطة الراديو التي يشغلها CJ ونوع الموسيقى (Hip-Hop، Rock، Funk، WCTR).
  * **الوعي بالوقت**: التعليق على الفجر والشروق، الظهيرة، الغروب أو منتصف الليل.
  * **الدفاع التلقائي والـ Drive-By**: إطلاق النار على الأعداء والعصابات المعادية تلقائياً عند تعرض CJ لهجوم، أو إخراج الجسد من نافذة السيارة وإمطار الأعداء بالرصاص.

## 📋 المتطلبات الأساسية

1. **لعبة GTA San Andreas الأصلية (الإصدار v1.0 US)**:
   * يجب أن يكون ملف `gta_sa.exe` بحجم 14.3 ميجابايت (الإصدار الكلاسيكي).
2. **CLEO Redux**:
   * مثبت داخل مجلد اللعبة (`cleo_redux.asi`). يمكن تحميله مجاناً من [re.cleo.li](https://re.cleo.li/).
3. **بايثون Python 3.10 أو أحدث**:
   * مع التأكد من تفعيل خيار `Add Python to PATH` أثناء التثبيت.
4. **مفتاح مجاني لـ Groq Cloud API**:
   * احصل عليه خلال ثوانٍ من [console.groq.com/keys](https://console.groq.com/keys).

## 🚀 طريقة التثبيت والتشغيل

### 1. تنزيل المشروع
```bash
git clone https://github.com/bio-colab/gta-sa-ai-companion.git
cd gta-sa-ai-companion
```

### 2. تثبيت مكتبات بايثون
```bash
pip install -r requirements.txt
```

### 3. ضبط مفتاح الـ API
قم بنسخ ملف `.env.example` وتسميته `.env` داخل مجلد `AINPC/`، وضع مفتاحك:
```env
GROQ_API_KEY=gsk_your_groq_api_key_here
GROQ_MODEL=qwen/qwen3.8-27b
GROQ_STT_MODEL=whisper-large-v3-turbo
```

### 4. نسخ ملفات المود إلى مجلد اللعبة
انسخ الملفات التالية إلى مجلد تثبيت GTA San Andreas الرئيسي:
* `cleo/stage1_test[fs].js` ➔ `[مجلد اللعبة]/cleo/stage1_test[fs].js`
* `cleo/ainpc_bridge.ini`   ➔ `[مجلد اللعبة]/cleo/ainpc_bridge.ini`
* مجلد `AINPC/`             ➔ `[مجلد اللعبة]/AINPC/`

## 🎮 كيفية اللعب والتحكم

1. **تشغيل عقل الذكاء الاصطناعي**:
   قم بتشغيل الملف:
   ```bash
   python AINPC/bridge.py
   ```
   أو بالضغط مرتين على `AINPC/run_bridge.bat`.
   ستظهر لك الرسالة: `[BRIDGE READY] Waiting for GTA San Andreas...`

2. **تشغيل اللعبة**:
   * ادخل اللعبة وحمّل أي ملف حفظ.
   * ستظهر رسالة ترحيبية في أسفل الشاشة: `AI NPC READY - Press H near a ped!`.

3. **أزرار التحكم**:
   * **زر `H`**: اضغط عليه بالقرب من أي مواطن في الشارع لتجنيده. اضغط عليه مرة أخرى لتحريره وإعادته لحياته الطبيعية.
   * **زر `T` (الضغط والتحدث)**: اضغط باستمرار على `T` وتحدث في الميكروفون، ثم ارفع يدك عن الزر عند الانتهاء. سيرد عليك المرافق فوراً بترجمة ملونة وينفذ حركات اللعبة المطلوبة!
